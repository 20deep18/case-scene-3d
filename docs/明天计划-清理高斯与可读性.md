> 用户观察：模型里有大量不需要的高斯。**判断：说得对**，但垃圾分几类，手段不同，

## 一、先说清楚：什么是"无用高斯"

按"为什么要删"分四类，**每类对应不同手段**：

| 类型 | 表现 | 为什么产生 | 手段 | 风险 |
| --- | --- | --- | --- | --- |
| **A 低不透明度的雾** | 外圈一片白/灰的半透明感 | 大量小尺度、低 alpha 的高斯叠加（实测不是巨型高斯） | 按**模型自身分位**过滤（如 opacity < P5 且 scale < P10），**不用绝对值** | 中（阈值过狠会削薄表面） |
| **B 空中漂浮点** | 偏离表面、孤立的碎点 | 位姿误差 + 初始点噪声 | **统计离群点剔除（SOR）**：k 近邻距离的均值超阈值就删 | 中（参数太狠会把薄结构删掉） |
| **C 视野外的高斯** | 房间外的拉长条纹、室外碎块 | 相机没真正看过，属于"脑补" | **视锥覆盖计数**：把所有相机视锥投一遍，没有任何相机能看到的直接删 | 低（看不到的本来就不该画） |
| **D 房间外的溢出** | 建筑外墙外的杂乱点 | 点云里带进了走廊/窗外 | **房间盒裁剪**（只保留盒内 + 10% 边距） | 中（房间盒本身不准时不能裁，比如宿舍） |

**关键约束**：A/B/C 是"逐点"判据，D 依赖房间盒质量。
宿舍的房间盒不可信（部分视角），所以 **D 只在 room-real / 卫生间 上用**；
宿舍只做 A+B+C。

## 一·补：先量了一遍，**推翻了我自己的一个假设**

| 模型 | 高斯数 | opacity P50 | opacity<0.15 | scale P50 / max | 近白且淡 |
| --- | --- | --- | --- | --- | --- |
| 宿舍现场-彩色-精简 | 399,649 | **0.247** | 33.7% | 0.0069 / 0.051 | 8.8% |
| room-real | 59,919 | **0.020** | 81.1% | 0.1377 / 0.341 | 21.4% |

**两个结论（影响手段选择）**：
1. **不能按绝对透明度阈值删**：两个模型的 opacity 分布差一个数量级（P50 0.247 vs 0.020）。
   照"删 opacity<0.05"跑，宿舍一个不删、room-real 直接删掉 67%（把好模型删废）。
   → 所有阈值必须**按模型自身分位**取（P5/P10 那种），不能写死。
2. **"大白球"不是单个大高斯**：宿舍的 scale 最大只有 0.051（P50 是 0.0069，只差 7 倍），
   所以画面的白雾是**大量小尺度、低透明度的高斯叠出来的**，不是几个巨型高斯。
   → 光靠"删大高斯"没用，**必须靠密度/可见性判据**（SOR + 视锥覆盖）。

（注：`.splat` 是**逐记录交错**的 32 字节格式，解析必须用结构化 dtype；
第一版我按结构体数组读，scale 全是 NaN —— 差点据此写出错误的计划。）

# 高斯清理（11-04 上午，已落地）

## 一、先纠正一个假设（实测推翻了）

原以为"外圈白雾 = 几个巨型高斯 + 低透明度"，量完发现：

| 现象 | 实测 |
| --- | --- |
| 宿舍高斯 scale | P50 0.0069 / P99 0.0505 / max 0.051（**只差 7 倍**，不是巨型） |
| 那些"大白球"周围 | 3×自身尺度内有 **1074~18113 个邻居** → **不是孤立浮点**，是"盖在细密表面上的一层大高斯" |
| opacity 分布 | 宿舍 P50 0.247，room-real P50 0.020 → **差一个数量级，绝对阈值不可用** |

**结论**：白球的成因是**大尺度高斯覆盖在小尺度表面之上**（3σ 渲染出来就是一片大圆斑）。
所以正确手段是**按尺度分位删顶部**，删掉之后底下的细密表面还在。

## 二、工具 `tools/prune_splat.py`（新）

五类过滤器，各自独立开关，逐项报告删了多少：
`--opacity-pct`（按模型自身分位）、`--scale-pct`（同上）、`--sor-k`（体素密度）、
`--frustum-min` + `--poses`（视锥覆盖：相机没看过的删掉）、`--structure` + `--box-margin`（房间盒裁剪，
**房间盒标了推测/不可信时自动跳过**，避免裁掉真表面）。

## 三、实测效果（宿舍）

| 配置 | 高斯数 | 文件 | 观感 |
| --- | --- | --- | --- |
| 原模型 | 399,649 | 12.20 MB | 外圈一片灰白大球 |
| opacity<P10 + 视锥 + 密度 | 330,936 | 10.10 MB | **更糟**（删掉小的，大球更显眼） |

| **只删尺度最大 10%（P90）** | **359,684** | **10.98 MB** | ✅ **大球基本消失，彩surface露出** |

# 可读性改造：竖直刻度尺（11-04）

## 做了什么

`app/web/js/structure-layer.js` 新增 `setRuler()` / `_addRuler()`：
在场景一角画**一条从地面到顶部的竖线 + 3~4 条横刻度 + 数字标签**，
让"这是 2.88 单位高的空间、床面在 0.96 单位"这种空间关系一眼可见。

- **锚点**：优先取房间盒"离地最近的那个角"（贴着地面、就在房间内），没有房间盒时退回包围盒最小角
- **刻度数**：3~4 条（实测 7 条会挤成一团），**不标 0**（地面看得出来）
- **标签**：带 12px 屏幕偏移，避免压在竖线上；文字用 `_sizeText` 同一套规则 ——
  **没标定写"单位"、标定了才写"m"**
- 随「结构线」开关一起显示（没有新增 UI 控件）

## 已知不足

- 刻度尺的竖轴与视线接近平行时（俯视/侧视），刻度在屏幕上会挤在一起；
  目前靠"减少刻度数 + 标签偏移"缓解，没有做"标签避让"。
- 宿舍（VGGT）模型没有房间盒，锚点退回包围盒角，位置可能不在房间内 —— 可接受。

# 渲染参数接上了（真 bug）+ 30k 步训练（11-04 中午）

## 一、修掉一个"假控件"bug

`index.html` 里一直有「高斯尺寸 / 不透明度 / 曝光」三个滑杆，但：
- app.js **没有绑定任何事件**（值只写进 `state.filters`，没人读）
- 渲染器的着色器里**连 opacity/exposure 的 uniform 都没有**

→ 拖动滑杆画面纹丝不动。现在：
1. `splat-renderer.js` 新增 `uAlphaGain` / `uExposure` 两个 uniform（顶点着色器里乘到 alpha 与颜色上）
2. `app.js` 新增 `bindRenderSliders()`：滑杆 → `state.filters` → `renderer.options`
3. 渲染器**构造时**带上当前值（否则"加载模型前调过的值"会丢）

新增回归测试 `tests/browser_render_sliders.mjs`：**7/7**
（滑杆存在、初值一致、拖动后 options 真变、重建渲染器后继承当前值）。

## 二、实测出的观感甜点

| 参数组合 | 观感 |
| --- | --- |
| 1.00 / 1.00 / 1.00（原默认） | 表面糊、白雾重 |
| **0.80 / 0.75 / 1.10**（新默认） | **细节出来、白雾下降** ✅ |
| 0.62 / 0.62 / 1.05 | 更锐但开始颗粒化（能看清单个高斯） |

默认值已写入 `state.filters` 与三个滑杆的 `value`，两边一致。

# 可视化效果：一轮完整的参数实验（11-04 中午）

## 实验记录（都在宿舍模型上，同一机位）

| # | 做了什么 | 结果 |
| --- | --- | --- |
| 1 | 渲染参数三档对比 | 1/1/1 糊 → **0.8/0.75/1.1 细节最好** → 0.62/0.62/1.05 开始颗粒化 |
| 2 | 训练步数 12k → 30k | PSNR **16.37 → 18.89 dB**（+2.5），但**画面更白**（床垫颜色漂白） |
| 3 | SH 0 → 1（视角相关颜色） | PSNR **17.81**（比 sh0 低 1 dB），**颜色没找回来** |
| 4 | 训练步数+SH 都试过仍偏白 | 判定：**不是参数问题**，是这套 24 帧手持素材本身的亮度分布 |

## 结论与选择（诚实记录，含矛盾证据）

- **默认渲染参数**定为 `高斯尺寸 0.8 / 不透明度 0.75 / 曝光 1.1`：三档对比里细节最好、白雾最轻。
- **模型选 12k 版**（16.37 dB）：30k 版 PSNR 高 2.5 dB，但**颜色漂白**（原本棕色凉席变白），
  视觉上更差 —— 演示看的是观感，所以按视觉选。
- **一个未解的矛盾**：12k 版在**未抽稀**时能看到棕色凉席；**抽稀（删最大 10% 尺度）后**画面更白。
  说明"最大尺度的那个 10%"里既有灰白大球、也有**彩色大面片**（凉席、床板），一刀切会连后者一起删。
  → 明天可试：**按颜色/亮度分桶**抽稀（只删"近白且大"的），或按"是否在表面附近"区分。
