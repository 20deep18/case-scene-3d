# 家具级线稿：实测记录（2026-11-01）

> 目标：从**手机视频**直接出"家具级"三维线稿（衣柜/床/洁具这类），不是房间级的盒子。
> 结论先说：**算法验证通过，但你这段厕所素材出不来** —— 原因是素材，不是算法。下面是量出来的证据。

## 一、已建的链路

`tools/pipeline_furniture.py`：视频 → 抽帧 → COLMAP → 训练 .splat → 结构 → 家具盒 → 线稿（一条命令）。

拆开是：
- `pipeline/extract_frames.py` 抽帧 + 模糊剔除
- `pipeline/colmap_recon.py` 位姿（CPU 版 COLMAP，穷举匹配）
- `pipeline/train_gsplat.py` 3DGS 训练（**必须**经 `tools/msvc-env.bat` 包一层）
- `pipeline/to_splat.py` 导出 .splat
- `tools/scene_structure.py` 结构（曼哈顿系 + 房间盒）
- `tools/furniture_lines.py`（新）剥壳/剥平面 → 体素聚类 → 有向盒
- `tools/render_lineart.py --objects`（新）把家具盒画进线稿，并参与遮挡计算

## 二、算法验证：合成房间 4/4 命中

`tools/make_furnished_demo.py` 造了一间 4.6×3.6×2.8 m 的合成房间（衣柜 1.8×0.6×2.0、床 2.0×1.5×0.5、两个床头柜 0.45×0.4×0.52），已知真值：

| 家具 | 真值尺寸 | 算法输出 | 中心误差 |
| --- | --- | --- | --- |
| 衣柜 | 1.8×0.6×2.0 | 1.76×0.56×1.91 | 4 cm |
| 床 | 2.0×1.5×0.5 | 2.04×1.54×0.44 | <1 cm |
| 床头柜 A | 0.45×0.4×0.52 | 0.49×0.44×0.45 | <1 cm |
| 床头柜 B | 0.45×0.4×0.52 | 0.48×0.44×0.45 | <1 cm |

高度普遍偏短 8~12%：家具**底面贴地被"剥壳"一起剥掉了**，属于可解释的系统性偏差。

## 三、真实厕所素材：三处硬阻断

素材：`厕所测试1 (1).mp4`（150 s）与 `(2).mp4`（191 s），1920×1080 @30fps。

| 指标 | 视频 1 | 视频 2 |
| --- | --- | --- |
| 抽帧（fps 2 / 模糊剔除） | 263 / 300 | ~270 / 310 |
| COLMAP 注册 | **219/263 = 83.3%** | **269/310 = 86.8%** |
| 稀疏点 / 重投影误差 | 32,539 / 1.12 px | 35,590 / 1.16 px |
| 训练（16k~30k 步） | 39,741 高斯，PSNR 19.3~21.2 dB | 51,154 高斯，PSNR 18.8 dB |
| 结构自检 | ❌ 只有 1 面可信竖墙，房间盒 10.9×15.4×5.5 m | ❌ 1 面墙，14.9×12.6×5.7 m |
| 家具盒 | 0 个（剥平面后剩 1,007~5,044 点，碎成 60~300 点小块） | 2 个（425 / 330 点，尺寸像洁具但无法确认） |

**根因（量出来的）**：
- 厕所是**白瓷砖**：`analyze_model_fog.py` 显示 51,154 个高斯里 **33% 近白、只有 1% 有色**，PSNR 只有 19~21 dB；
- 应用里打开这个模型是一团**白色雾球**（见 `output/bathroom/v2-shot.png`），认不出洁具；
- 表面在几何上不成立 → 结构拟合只找到 1 面墙 → 家具分割只剩墙上的碎点。

**判断：白瓷砖 + 反光是 3DGS 的最差输入（弱纹理、各向同性、强高光）。这条素材的几何上限就在这里，加迭代/加分辨率都没救**（实测：7k→30k 步只从 22,295 长到 23,295 个高斯；downscale 1 后 48k 高斯但 PSNR 反降到 19.3）。

## 四、下一步建议

1. **重拍一间"有家具 + 有纹理"的屋子**（推荐，也最贴 PPT 叙事：卧室/衣柜）：
   - 白墙/白瓷砖前**放点东西**（毛巾、瓶子、纸箱都能提供纹理）；
   - 家具要**绕到侧面/斜角**拍，别只拍正面；
   - 家具之间留空档；离家具近一点、多停两秒；
   - 慢走、别甩镜头（模糊帧会被剔除，实测剔了 12~14%）。
2. 若必须用这间厕所：走 **COLMAP MVS 稠密重建**（`patch_match_stereo` + `stereo_fusion`）拿真实表面点，但本机 COLMAP 是 **CPU 版**，269 张图预计数小时，且厕所白墙仍可能融不出面。
3. 演示兜底：**合成房出家具级线稿**（已验证）+ 真实素材出**房间级**线稿，并在 PPT 里如实说明素材限制。

## 五、踩过的坑（都已修，供以后复用）

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| `PermissionError: torch_extensions` | JIT 缓存默认在 `%LOCALAPPDATA%`（被拒目录） | 用 `tools/msvc-env.bat` 包一层（它把缓存指到工作区） |
| `Ninja is required` | 缺 ninja | `msvc-env.bat` 自带 VS 的 ninja；**别再在同一行用 `%PATH%` 拼 PATH**（会在 call 之前展开，把 cl 抹掉） |
| `缺少依赖 torch` | 误用 DSH 的 Python | 必须用 `pyruntime312\python.exe`（torch 在 `pydeps312`） |
| 家具盒 = 整间屋 | 小空间里"按房间盒剥壳"等于没剥 | 加**平面剥离**（RANSAC 墙/地/顶） |
| 房间盒不可信时链崩 | 硬依赖 structure.json | 加**相机轨迹兜底**（离相机群太远视为噪声） |
| Alpha 过滤把 89% 点扔了 | 厕所模型 alpha 中位只有 0.047 | `--min-alpha` 默认降到 0.02 |
| 合成点太稀导致只找到一个柜 | 每面 233 点、间距 11 cm > 体素 3.5 cm，大面碎成孤立体素 | 加密到每件 9000 点 |
