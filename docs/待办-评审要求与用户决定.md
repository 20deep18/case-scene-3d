### 断言的 21 项（390×844 + 1280×800 两种视口）

- 手机：画布宽 ≈ 视口宽、两栏默认在屏幕外、抽屉按钮可见且 **≥44px**、顶栏 FPS/高斯收起、遮罩默认不可见
- 交互：点左按钮 → 左栏滑入 + 遮罩出现；点遮罩 → 收起；开右栏时左栏自动关
- 桌面：两栏常驻、抽屉按钮隐藏、FPS 恢复、`body` 上不留抽屉类

### 关键经验（写下来避免下次再踩）

1. **手势本来就有**：`OrbitControls` 原生的触摸映射就是"单指旋转 / 双指缩放+平移"，
   不需要自己写 —— 这轮只做了布局，没碰相机控制。
2. **测试会和 CSS 过渡动画赛跑**：第一版"先导航再改视口"，600ms 后读到的是动画中间态，
   同一份代码两次结果不同（一次"没关"一次"没开"）。改成 **先设视口 → 再导航 → 注入
   `*{transition:none}`** 之后 21/21 稳定通过。
3. **截图必须看**：这轮手机截图暴露了顶栏溢出（模式按钮被挤成竖列）和底栏吃掉 1/3 屏高，
   而断言全绿 —— 断言只验"是否在屏幕外/尺寸够不够"，验不出"挤成一列"。
