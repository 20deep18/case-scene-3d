# 三个演示模型：它们各自在证明什么（PPT 用）

> 用途：把这三张截图放进 PPT 时，每张配一段"技术内涵"的说明。
> 顺序 = 静态包里的顺序，也是演示时的讲解顺序。

---

## ① 宿舍现场-彩色-精简 —— **证明"AI 能从视频里认出家具"**

| 项 | 数值 |
| --- | --- |
| 体积 | 11.3 MB / **371,043 高斯** |
| 来源 | 手机手持视频 24 帧 → **VGGT** 出位姿+深度 → 3DGS 训练 12k 步（PSNR 16.37 dB） |
| 覆盖 | **5 个物体盒**：`bed 83%`、`cabinet 78%`、`chair 69%`、`desk 58%`、`door 38%` |
| 截图 | `output/judge-1-dorm.png` |

**它证明的三件事**：
1. **位姿来源可以不是 COLMAP**：宿舍这段素材用 COLMAP 会尺度爆炸（点云长宽比 2.94），
   换 **VGGT**（CVPR 2025 最佳论文）一次前向就拿到了可用的位姿与稠密深度。
2. **物体是"认"出来的，不是"人框的"**：Grounding DINO 开放词表检测（10 个英文短语逐条推理）
   → 取框内像素的深度中位数 → 反投影成三维盒。171 个原始框 → 跨帧合并 7 件 → **去重后 5 件**。
3. **盒子会自我解释**：每个盒子带**类别 + 置信度**，颜色按类别编码（床蓝/门黄/柜绿/桌紫/椅橙）；
   同一片区域被识成多个类别时，用**类别层次 + 3D IoU** 抑制（7→5）。

**讲的时候强调**："这是**语义**层，不是几何层 —— 评委看到的每个盒子背后都有一个英文短语。"

## ② room-real —— **证明"结构线是算出来的，不是画上去的"**

| 项 | 数值 |
| --- | --- |
| 体积 | 1.4 MB / **44,799 高斯**（已去掉近白大球与最大 15% 尺度） |
| 来源 | COLMAP 稀疏点云（5 面可信竖墙）→ 3DGS |
| 结构 | 房间盒 **17.14 × 9.19 × 2.88**，墙 5 面，地面网格 + 相机轨迹 |
| 截图 | `output/judge-room-v3.png` |

**它证明的三件事**：
1. **房间尺寸是拟合出来的**：RANSAC 反复找竖直平面 → 按墙法向**角度聚类**定曼哈顿正交三轴
   → 每个方向取最外侧墙面做**半空间求交**。这条链和"深度学习"无关，是纯几何，**可解释、可复现**。
2. **精度可验证**：与真值比 **0 / 0.9 / 0.1%**（长度/宽度/高度），是整套系统里最硬的一个数字。
3. **界面上的数字是有单位的**：标注写"17.14 单位"而不是"米" —— 因为重建尺度本身是任意的，
   填了卷尺实测值才会换算成米（这个"不谎称"的设计本身就是加分项）。

**讲的时候强调**："青色是房间盒、黄色是墙、白色是地面网格 —— **这三套线全是从点云里算出来的**。"

## ③ 柜子现场-致密 —— **证明"渲染质量能到什么程度"**

| 项 | 数值 |
| --- | --- |
| 体积 | 5.2 MB / **171,252 高斯**（去掉了最大 15% 尺度与近白大球） |
| 来源 | 近距离环绕拍摄的稠密重建 → 3DGS |
| 观感 | **18~21 FPS**（无头浏览器软件渲染下的数字，真机更高），木色/蓝白细节清晰 |
| 截图 | `output/judge-cab-v3.png` |

**它证明的三件事**：
1. **3DGS 的细节能力**：近距离时能看清材质的明暗与颜色过渡（木纹、蓝白色件），
   这是网格重建（Mesh）在弱纹理处做不到的。
2. **观感是可以调的**：渲染参数（高斯尺寸 0.8 / 不透明度 0.75 / 曝光 1.1）与抽稀判据
   （只删"近白且大"的高斯）都能显著改变"雾感"，我们在页面上把这三个滑杆**真的接上了**。
3. **它同时也是一次"诚实的失败"**：这个模型的物体盒**没有画** ——
   因为盒子长边 16.76 m 是相机环绕半径 3.53 m 的 4.7 倍，明显被背景点撑大了。
   界面如实写"物体几何不可信，未画"，而不是硬画一个错盒子。

**讲的时候强调**："这一张是看**渲染上限**的；它同时说明我们宁可留白，也不画错。"

## 三个模型对应三层技术（一句话版，PPT 页脚可直接用）

| 模型 | 层 | 一句话 |
| --- | --- | --- |
| 宿舍 | **语义层（AI）** | VGGT 出几何、开放词表检测出物体，盒子里写着"这是什么、有多确定" |
| room-real | **几何层（结构）** | RANSAC + 曼哈顿正交 + 半空间求交，房间尺寸误差 0.9% |
| 柜子 | **表达层（渲染）** | 3DGS 让手机浏览器里也能看清材质与细节 |
